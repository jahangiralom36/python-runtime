# 📱 APK Studio (Android অ্যাপ)

ফোনেই যেকোনো APK খুলে **URL/লিংক, অ্যাপের নাম, টেক্সট, রং, আইকন/ছবি, পারমিশন** বদলে নতুন **সাইন করা APK** বানানোর অ্যান্ড্রয়েড অ্যাপ। সোর্স কোড লাগে না, কোনো ফাইল ইন্টারনেটে আপলোড হয় না।

**ইনস্টল:** `APKStudio.apk` ফোনে ইনস্টল করুন (Android 7.0+)। "অজানা উৎস থেকে ইনস্টল" চালু করতে হতে পারে।

## কীভাবে কাজ করে
- `classes.dex` এর ভেতরের স্ট্রিং (const-string ও static final String), `resources.arsc`, বাইনারি `AndroidManifest.xml` / `res/*.xml` ও `assets/` এর টেক্সট ফাইল সরাসরি প্যাচ করে (dexlib2 + নিজস্ব arsc/AXML এডিটর)।
- পারমিশন রিমুভ, ছবি বদল/মোছা, রং বদল।
- তৈরি APK zipalign হয়ে v1/v2/v3 স্কিমে সাইন হয় (apksig)। ডিফল্ট key অথবা নিজের `.p12/.pfx` keystore।

## ট্যাব
| ট্যাব | কাজ |
|---|---|
| 🔗 লিংক | সব URL ধরন অনুযায়ী সাজানো (API, Firebase, ওয়েবসাইট…)। প্রতিটি লিংকের নিচে দেখায় **কোন ফাইল/ক্লাস/পেজে** আছে ও আশেপাশের লেখা; নতুন লিংক লিখলেই দেখায় **কোথায় কী বদলাবে**। একটা একটা বা পুরো ডোমেইন একসাথে বদল |
| ✏️ টেক্সট | অ্যাপের নাম + সব strings (ভাষা অনুযায়ী) |
| 🎨 রং | colors এর কালার পিকার |
| 🖼️ ছবি | এক ছবি → সব লঞ্চার আইকন (অটো রিসাইজ); যেকোনো ছবি বদল/মোছা |
| 🔐 পারমিশন | পারমিশন রিমুভ |
| 🔎 খুঁজুন | কোড/রিসোর্স/assets এ খুঁজে বদল (AdMob ID, API key…) |
| 📁 ফাইল | যেকোনো টেক্সট/কনফিগ ফাইল (config.json, .properties, google-services.json…) সরাসরি খুলে পুরোটা এডিট করা যায় — আগে কী URL/API বসানো ছিল সেটা দেখে নতুন করে বসানো |
| 📦 বিল্ড | পরিবর্তনের তালিকা → APK তৈরি → সেভ / ইনস্টল / শেয়ার |

## সীমাবদ্ধতা
- নতুন key দিয়ে সাইন হলে আগের ইনস্টল করা অ্যাপের ওপর আপডেট হবে না → আগে আনইনস্টল করুন।
- প্যাকেজ নাম, layout XML ডিজাইন, নতুন পারমিশন যোগ — এই ভার্সনে নেই।
- প্রোটেক্টেড/প্যাকড (যেমন নিজের signature যাচাই করে) অ্যাপ বদলালে চালু না-ও হতে পারে।
- শুধু নিজের অ্যাপ বা অনুমতি আছে এমন অ্যাপে ব্যবহার করুন।

## নিজে বিল্ড করা
`./build.sh` (Java JDK 11+, curl, unzip, zip লাগবে; Gradle/Android SDK লাগে না) → `build/APKStudio.apk`।
সোর্স: `app/src/com/apkstudio/app/` (Engine, ResPool, ArscDoc, BinXml, DexTool, Signer, MainActivity), UI: `app/assets/ui.html`।
