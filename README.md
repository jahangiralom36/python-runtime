# 📱 APK Studio

APK আপলোড করে ভেতরের **URL, টেক্সট, রং, আইকন/ছবি, অ্যাপের নাম, পারমিশন, ফাইল** এডিট/রিমুভ করে আবার **সাইন করা APK** বানানোর লোকাল টুল।
সোর্স কোড ছাড়াই কাজ করে (apktool দিয়ে ডিকোড → এডিট → রিবিল্ড → সাইন)।

## চালানোর নিয়ম
1. **Python 3.8+** ও **Java (JDK/JRE 11+)** ইনস্টল থাকতে হবে (https://adoptium.net)
2. চালান:
   - Linux/Mac: `./run.sh`
   - Windows: `run.bat` এ ডাবল ক্লিক
3. ব্রাউজারে `http://127.0.0.1:8765` খুলবে। প্রথমবার apktool ও signer নিজে নেমে যাবে (ইন্টারনেট লাগবে)।

## ব্যবহার
| ট্যাব | কাজ |
|---|---|
| 🔗 URL | অ্যাপের কোড/স্ট্রিং/assets এর সব লিংক দেখায়; একটা একটা বা পুরো ডোমেইন একসাথে বদলানো যায় |
| ✏️ টেক্সট | strings.xml (সব ভাষা) এডিট / যোগ / মুছুন |
| 🎨 রং | colors.xml কালার পিকার দিয়ে |
| 🖼️ আইকন/ছবি | এক ছবি দিয়ে সব লঞ্চার আইকন বদল (অটো রিসাইজ), যেকোনো ছবি বদল/মুছুন |
| 🔐 নাম/পারমিশন | অ্যাপের নাম, প্যাকেজ, ভার্সন, পারমিশন রিমুভ/যোগ, http অনুমতি |
| 🔎 খুঁজুন-বদলান | সব ফাইলে (AdMob ID, API key ইত্যাদি) খুঁজে বদলানো, Regex সহ |
| 📁 ফাইল | যেকোনো ফাইল খুলে এডিট, মুছুন, নতুন ফাইল যোগ (layout, HTML, smali…) |
| 📦 বিল্ড | বিল্ড + সাইন (ডিফল্ট debug key, বা নিজের keystore) → APK ডাউনলোড |

## জেনে রাখুন
- নতুন key দিয়ে সাইন হলে আগের ইনস্টল করা অ্যাপের ওপর আপডেট হবে না → আগে আনইনস্টল করুন। একই key চাইলে নিজের keystore দিন।
- অ্যাপ প্রোটেক্টেড/অবফাসকেটেড হলে বা অ্যাপ নিজের signature যাচাই করলে ডিকোড/রান সমস্যা হতে পারে।
- ডেটা `workspace/` ফোল্ডারে থাকে; ফাইল আপনার কম্পিউটারের বাইরে যায় না। শুধু `127.0.0.1` এ চলে।
- শুধু নিজের অ্যাপ বা যে অ্যাপ বদলানোর অনুমতি আছে সেটাতেই ব্যবহার করুন।
